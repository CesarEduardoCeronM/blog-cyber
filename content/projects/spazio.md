**Spazio** es un sistema en desarrollo diseñado para optimizar la gestión de activos inmobiliarios. El enfoque principal de este proyecto es la trazabilidad de las operaciones y la seguridad de la información sensible de arrendadores y arrendatarios.

## Estado del Proyecto
Actualmente se encuentra en fase de desarrollo de módulos centrales. Se están aplicando las lecciones aprendidas en *Aureum* para mejorar la resiliencia del sistema y la seguridad de las APIs.

### Objetivos Técnicos
*   **Integridad de Datos:** Implementación de políticas de seguridad a nivel de base de datos (RLS) en Supabase.
*   **Auditoría:** Registro de logs de actividad para cada transacción inmobiliaria.
*   **Escalabilidad:** Arquitectura modular que permita el crecimiento de la plataforma.
